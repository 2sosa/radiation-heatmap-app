# radiation-heatmap-app

## 📍 放射線ヒートマップ作成ツール

### 概要
AccuradのCSVデータから放射線ヒートマップを作成するStreamlitアプリケーションです。

### 主な機能
- 📊 CSVファイルからの放射線データ読み込み
- 🗺️ インタラクティブなヒートマップの生成
- ⏰ **タイムスタンプの自動変換（UTC → JST）**
- 🔍 時間範囲によるデータフィルタリング
- 📥 処理済みデータのダウンロード

### タイムスタンプ処理について

#### 問題の背景
Accurad本体では時刻がUTC+9（日本標準時）で表示されますが、CSVエクスポート時にはUTC（協定世界時）で出力されます。
例：Accurad本体で「12:00」と表示される時刻が、CSVでは「3:00」として記録される（9時間の差）

#### 解決方法
このアプリケーションは以下の処理を自動的に行います：

1. **タイムスタンプカラムの自動検出**
   - "timestamp", "time", "date", "datetime", "時刻", "日時" などのキーワードを含むカラムを自動検出

2. **UTC → JST変換**
   - CSVのUTC時刻を自動的にJST（UTC+9）に変換
   - 元のUTC時刻と変換後のJST時刻の両方を保持

3. **データ突合・フィルタリング**
   - JST変換後の時刻を使用してデータをフィルタリング
   - Accurad本体の表示時刻と一致する形でデータを処理

### 使用方法

1. **CSVファイルのアップロード**
   - Accuradからエクスポートしたセミコロン区切りのCSVファイルをアップロード

2. **タイムスタンプの確認**
   - アプリが自動的にタイムスタンプカラムを検出し、UTC→JST変換を実行
   - 変換結果がデータプレビューで確認可能

3. **時間範囲フィルタリング（オプション）**
   - 必要に応じて、JST基準で日時範囲を指定してデータをフィルタリング

4. **ヒートマップの生成と保存**
   - フィルタリング後のデータでヒートマップを自動生成
   - HTMLファイルとしてダウンロード可能
   - 処理済みCSV（JST時刻含む）もダウンロード可能

### 必要なパッケージ

```bash
pip install -r requirements.txt
```

