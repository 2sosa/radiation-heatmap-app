# Zip JSON Reader for Pythonista3

iPhoneのファイルアプリからzipファイルを選択し、中身のJSONファイルを読み取るPythonista3用スクリプトです。

## 機能

- iPhoneのファイルアプリからzipファイルを手動選択
- zipファイル内のJSONファイルを自動検出・読み取り
- JSONファイルの概要表示
- 詳細内容の表示オプション

## 使用方法

1. Pythonista3で `zip_json_reader.py` を実行
2. ファイル選択ダイアログでzipファイルのパスを入力
3. 自動的にzipファイルが解凍され、JSONファイルが読み取られます
4. 結果の概要が表示されます
5. 必要に応じて詳細内容を表示できます

## 特徴

- 大量のJSONファイルを含むzipファイルに対応
- エラーハンドリング付き
- ファイルサイズとデータ型の情報表示
- 日本語対応（UTF-8エンコーディング）

## 必要な環境

- Pythonista3
- iOS デバイス
- zipファイル（JSONファイルを含む）
