# radiation-heatmap-app

## 📍 放射線ヒートマップ作成ツール

### 概要
JSONファイル（ZIP形式）から放射線ヒートマップを作成するStreamlitアプリケーションです。
iPhoneのファイルアプリからの手動選択とPythonista3での読み取りに対応しています。

### 主な機能
- 📂 **ZIPファイルからのJSONデータ読み込み**
- 🔍 **自動カラム検出**（緯度・経度・線量率）
- 🗺️ インタラクティブなヒートマップの生成
- ⏰ **タイムスタンプの自動変換（UTC → JST）**
- 🔍 時間範囲によるデータフィルタリング
- 📊 データ品質チェック
- 📥 処理済みデータのダウンロード

### タイムスタンプ処理について

#### 問題の背景
Accurad本体では時刻がUTC+9（日本標準時）で表示されますが、CSVエクスポート時にはUTC（協定世界時）で出力されます。
例：Accurad本体で「12:00」と表示される時刻が、CSVでは「3:00」として記録される（9時間の差）

#### 解決方法
このアプリケーションは以下の処理を自動的に行います：

1. **タイムスタンプカラムの自動検出**
   - "timestamp", "time", "date", "datetime", "時刻", "日時" などのキーワードを含むカラムを自動検出

2. **UTC → JST変換**
   - CSVのUTC時刻を自動的にJST（UTC+9）に変換
   - 元のUTC時刻と変換後のJST時刻の両方を保持

3. **データ突合・フィルタリング**
   - JST変換後の時刻を使用してデータをフィルタリング
   - Accurad本体の表示時刻と一致する形でデータを処理

### 📱 iPhone + Pythonista3での使用方法

#### 1. データの準備
- 放射線測定データをJSON形式で準備
- 大量のJSONファイルがある場合は、ZIP形式に圧縮

#### 2. ファイルの選択
- iPhoneのファイルアプリから該当のZIPファイルを選択
- アプリにZIPファイルをアップロード

#### 3. 自動処理
- **ZIPファイル展開**: 自動的にZIP内のJSONファイルを検出・展開
- **カラム自動検出**: 緯度・経度・線量率のカラムを自動識別
- **データ変換**: 必要に応じて数値型に自動変換
- **品質チェック**: データの欠損値や異常値をチェック

#### 4. フィルタリング（オプション）
- タイムスタンプがある場合、JST基準で日時範囲を指定してフィルタリング可能

#### 5. ヒートマップ生成
- インタラクティブなヒートマップを自動生成
- HTMLファイルとして保存・ダウンロード可能
- 処理済みJSONデータもダウンロード可能

### 📊 対応データ形式

JSONファイルには以下のデータが含まれている必要があります：

#### 必須フィールド
- **緯度**: `latitude`, `lat`, `緯度` など
- **経度**: `longitude`, `lon`, `lng`, `経度` など  
- **線量率**: `dose`, `radiation`, `線量`, `µSv/h`, `uSv/h` など

#### オプションフィールド
- **タイムスタンプ**: `timestamp`, `time`, `date`, `datetime`, `時刻`, `日時` など

### 🔧 自動機能
- **カラム名の柔軟な検出**: 様々な命名規則に対応
- **データ型の自動変換**: 文字列から数値への自動変換
- **エラーハンドリング**: 不正なデータの検出と警告表示
- **データ品質チェック**: 欠損値や異常値の自動検出
